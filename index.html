Pengaturan Domain Utama

Gunakan domain atau subdomain pribadi Anda sendiri sebagai alamat default shortlink (contoh: s.domainanda.com atau link.domainanda.com).

Jangan sertakan https:// atau tanda garis miring (/).
Catatan DNS Setting (Untuk Anda masukkan di Registrar/Cloudflare):
  • Jika Subdomain (misal s.domainanda.com): Tambahkan DNS Record CNAME dengan Name s mengarah ke cname.vercel-dns.com.
  • Jika Domain Utama (misal domainanda.com): Tambahkan DNS Record A dengan Name @ mengarah ke IP 76.76.21.21.
  • Di Vercel: Masuk ke Project Settings > Domains dan tambahkan domain yang sama.

Cloud Backend & Google Auth

Status: Mode Penyimpanan Lokal

Tautan saat ini hanya tersimpan di browser perangkat ini. Hubungkan dengan Supabase (Gratis) untuk mengaktifkan login Google dan akses global dari perangkat manapun.

Ditemukan di Supabase Dashboard > Project Settings > API > Project URL.
Ditemukan di Supabase Dashboard > Project Settings > API > Project API keys (anon public).
Panduan Singkat Setup Google Login & Database (Hanya 3 Menit):
  1. Buat Akun / Project Baru: Buka supabase.com dan buat project baru gratis.
  2. Jalankan Script Database: Buka menu SQL Editor di Supabase, lalu jalankan perintah SQL berikut: 
    -- 1. Tabel Links (Tautan)
create table if not exists public.links (
  id text primary key,
  user_id uuid references auth.users(id) on delete cascade,
  user_email text,
  slug text not null unique,
  destination_url text not null,
  title text,
  og_title text,
  og_description text,
  og_image text,
  clicks integer default 0,
  is_active boolean default true,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 2. Tabel Clicks (Analisis Statistik 1-7 Hari)
create table if not exists public.clicks (
  id text primary key,
  link_id text references public.links(id) on delete cascade,
  slug text not null,
  referer text,
  user_agent text,
  clicked_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 3. Row Level Security & Akses Terbuka
alter table public.links enable row level security;
alter table public.clicks enable row level security;

create policy "Allow all links access" on public.links for all using (true) with check (true);
create policy "Allow all clicks access" on public.clicks for all using (true) with check (true);
  3. Aktifkan Google Login: Buka Authentication > Providers > Google di Supabase, lalu masukkan Client ID dan Client Secret dari Google Cloud Console.
  4. Tambahkan Redirect URL di Google Cloud: Masukkan URL Callback Supabase Anda (misal https://xxxxx.supabase.co/auth/v1/callback) ke dalam Authorized Redirect URIs di Google Cloud Console.
